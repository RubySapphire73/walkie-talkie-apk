# 📻 무전기 받는 곳

단청과 와이프가 쓰는 무전기 앱의 설치 파일만 두는 곳이에요.

## 최신판 받기 (지금: 6판)
https://github.com/RubySapphire73/walkie-talkie-apk/raw/main/walkie-talkie.apk

이 링크는 늘 같아요. 열면 언제나 가장 새 판이 받아져요.

## 판 기록
| 판 | 바뀐 것 |
|---|---|
| 6 | 끊김 고침 (와이파이·블루투스를 흔들지 않는 연결), 끊기면 저절로 다시 붙기, 연결 기록 |
| 5 | 새 디자인, 위젯을 동그란 버튼으로(1~4칸), 소리 시험은 치직만, 무음 모드에서도 진동 |
| 4 | 목소리 키우기를 슬라이드로 (1.0~6.0배) |
| 3 | 목소리 키우기(1~4배), 잠긴 화면에서 바로 말하기, 앱 안에서 새 판 받기 |
| 2 | 받을 때 치직 소리 + 가벼운 진동, 소리 크기 막대 고르기, 소리 시험 버튼 |
| 1 | 처음 판: 근처 연결, 짝 맺기, 홈 화면 위젯 버튼 |

지난판은 `지난판` 폴더에 있어요.
